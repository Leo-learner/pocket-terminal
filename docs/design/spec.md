# 手机终端设计

视觉参考：mobile-concept.png，390 × 844 比例。全屏 #101214，工具栏与按键 #1b1e22，正文 #eeeee8，在线/选中 #b7e48b。系统字体用于操作，Menlo 等宽字体用于真实终端。顶栏 56px，会话栏 38px；终端弹性占满；工具栏 44px + 两排 44px 按键。iOS safe-area 与 visualViewport 动态高度。

组件：TopBar、SessionTabs、TerminalView、KeyBar、Login、Sheet。保持紧凑无卡片，1px 分隔，6px 按键圆角。禁止演示日志进入真实终端。图中的命令仅为设计参考。

必需的功能扩展：登录页；空会话状态；新建/重命名/结束会话抽屉；中文输入区；可选择的复制区；字号设置；明确在线/重连/离线状态。独立登录密钥，完全自托管资源。无服务工作线程缓存终端或凭据。
